## 📖 Sobre o repositório

Este repositório é destinado ao armazenamento e à organização de códigos e atividades desenvolvidos durante o primeiro ano de estudos em programação utilizando a linguagem **Java**.

O objetivo é registrar o processo de aprendizagem, reunir exemplos práticos e documentar a evolução dos conhecimentos em desenvolvimento de software.

## 🎯 Objetivos

- Praticar os fundamentos da programação com Java.
- Desenvolver o raciocínio lógico e a resolução de problemas.
- Aplicar conceitos de programação em atividades práticas.
- Organizar códigos e exercícios para futuras consultas.
- Registrar a evolução do aprendizado ao longo das aulas.

## 💻 Tecnologias e ferramentas

## 📂 Organização do repositório

O repositório reúne os materiais produzidos durante as aulas, permitindo consultar as implementações e acompanhar a evolução dos exercícios.

Cada arquivo ou projeto representa uma atividade prática, um exemplo de programação ou um exercício desenvolvido no contexto das aulas.

## 🚀 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/GustavoCCamargo/Aulas_Java_1_ano.git
```

**2. Acesse a pasta:**

```bash
cd Aulas_Java_1_ano
```

**3. Abra o projeto em uma IDE compatível com Java.**

Para arquivos Java independentes, é possível compilar e executar pelo terminal:

```bash
javac NomeDoArquivo.java
java NomeDaClasse
```

> **Observação:** os comandos acima são exemplos para arquivos Java simples. Projetos com pacotes, dependências ou estruturas específicas podem exigir procedimentos diferentes.
